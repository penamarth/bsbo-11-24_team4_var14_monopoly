Game "1" -down- "2..6" Player : Включает
Game "1" -right- "1" Board : Разыгрывается на
Game "1" -right- "1" Dice : Использует
Game "1" -- "2" Deck : Использует
Game "1" -- "0..1" Auction : Инициирует

Board "1" -down- "40" Square : Состоит из {упорядочено}

Square <|-- Property

Deck "1" -down- "*" Card : Содержит

Player "1" -- "1" Square : Находится на
Player "0..*" -- "0..1" Property : Владеет

Bank "1" -- "0..*" Street : Выдаёт дома/отели для

Auction "0..1" -- "1" Property : Разыгрывает
Auction "1" -- "2..*" Player : Участвуют
