# UC4. Игрок становится банкротом — краткое описание

**Действующее лицо:** система (инициируется автоматически)
**Предусловия:** у игрока не хватает денег для обязательного платежа
**Постусловия:** долг покрыт, либо игрок объявлен банкротом и его имущество распределено; при остатке одного игрока — партия завершена

Система пытается покрыть долг за счёт продажи построек должника → если денег хватило — платёж проведён, игрок продолжает игру → если не хватило — игрок объявляется банкротом, его имущество передаётся кредитору (игроку) или возвращается в банк → игрок исключается из очереди → проверяется, остался ли один игрок → если да, определяется победитель.

---

# Системные операции

### - handleBankruptcy(debtorID, creditorID, amount)
**Предусловия:** `debtor.CanAfford(amount) == false`
**Постусловия:** запущена процедура покрытия долга (см. операции ниже); по результату — либо долг списан, либо `debtor.IsBankrupt == true`

### - sellBuildingsBack(debtorID)
**Предусловия:** вызывается из handleBankruptcy, если у должника есть постройки (дома/отели)
**Постусловия:** дома/отели должника возвращены в `Bank` (`Bank.ReturnHouse` / `Bank.ReturnHotel`); должнику зачислена сумма от продажи; `Street.HouseCount` и `Street.HasHotel` обнулены для проданных построек

### - declareBankrupt(debtorID)
**Предусловия:** после `sellBuildingsBack` средств всё ещё недостаточно (`debtor.CanAfford(amount) == false`)
**Постусловия:** `debtor.IsBankrupt = true`; должник помечен как выбывший из очереди ходов

### - transferProperties(debtorID, creditorID)
**Предусловия:** `debtor.IsBankrupt == true`
**Постусловия:**
- если `creditorID` указан (кредитор — игрок): все объекты `Property` из `debtor.Properties` перенесены в `creditor.Properties`, `Property.Owner` обновлён на `creditor`;
- если `creditorID` не указан (кредитор — банк): `Property.Owner` для всех объектов должника обнуляется, `debtor.Properties` очищается — клетки становятся снова доступны для покупки.

### - checkGameOver()
**Предусловия:** вызывается после каждого завершения процедуры банкротства
**Постусловия:** возвращает `true`, если среди игроков остался ровно один не-банкрот, иначе `false`

### - getWinner()
**Предусловия:** `checkGameOver() == true`
**Постусловия:** возвращает единственного оставшегося активного игрока как победителя партии
