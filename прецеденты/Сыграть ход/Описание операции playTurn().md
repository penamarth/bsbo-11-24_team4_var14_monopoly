# UC2. Сыграть ход — краткое описание

**Действующее лицо:** текущий Игрок
**Предусловия:** игра начата, игрок не в тюрьме
**Постусловия:** фишка перемещена, эффект клетки обработан, балансы обновлены, ход передан следующему игроку

Игрок бросает кубики → система перемещает фишку → определяет тип клетки и обрабатывает её (покупка/аренда/карта/налог/тюрьма) → при нехватке денег запускается UC4 «Банкротство» → ход передаётся следующему.

---

# Системные операции

### - rollDice()
**Предусловия:** есть текущий игрок, не в тюрьме
**Постусловия:** сгенерированы значения d1, d2; вычислена сумма total

### - moveToken(playerID, steps)
**Предусловия:** бросок выполнен
**Постусловия:** player.position изменено; если пройден круг — начислены деньги за «Старт»

### - resolveSquare(playerID, squareID)
**Предусловия:** фишка перемещена
**Постусловия:** определён тип клетки; вызвана соответствующая операция (offerPurchase / chargeRent / drawCard / payTax / sendToJail)

### - chargeRent(payerID, ownerID, squareID)
**Предусловия:** клетка занята другим игроком
**Постусловия:** вычислена аренда; списана с payer, зачислена owner; при нехватке средств — declareBankruptcy (UC4)

### - drawCard(deckType)
**Предусловия:** попадание на Шанс/Казну
**Постусловия:** извлечена верхняя карта; применён её эффект; карта возвращена в колоду или удалена

### - payTax(playerID, squareID)
**Предусловия:** попадание на клетку «Налог»
**Постусловия:** сумма списана с игрока, зачислена банку; при нехватке средств — declareBankruptcy (UC4)

### - sendToJail(playerID)
**Предусловия:** попадание на клетку «В тюрьму»
**Постусловия:** player.position → клетка «Тюрьма»; player.status → «в тюрьме»; эффекты исходной клетки отменены

### - endTurn(playerID)
**Предусловия:** эффекты клетки обработаны
**Постусловия:** при дубле (не более 3 подряд) — повтор хода; при 3 дублях — sendToJail; иначе ход передан следующему игроку
