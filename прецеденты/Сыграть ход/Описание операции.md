# UC2. Сыграть ход

**Действующее лицо** — текущий игрок.

**Предусловие** — партия находится в состоянии `GameStatus.InProgress`, в меню выбран пункт `1`.

**Результат** — игрок пропускает ход в тюрьме либо перемещается и выполняет эффект клетки. Если партия продолжается, очередь переходит к следующему игроку без банкротства.

## Системные операции

### `Game.PlayTurn()`

При статусе `InProgress` получает текущего игрока через `Game.GetCurrentPlayer()`. Если игрок в тюрьме, вызывает `Player.TryLeaveJail()`, сообщает результат и передаёт очередь через `Game.AdvanceToNextPlayer()`. Бросок возобновляется со следующего хода этого игрока после освобождения.

В остальных случаях выполняет `Dice.Roll()`, `Player.Move(sum)`, `Board.GetSquare(player.Position)` и `Square.OnLand(player, game)` в этом порядке. После обработки клетки вызывает `Game.CheckGameOver()` и `Game.AdvanceToNextPlayer()`.

### `Dice.Roll()` и `Player.Move(int steps)`

`Dice.Roll()` сохраняет два значения от 1 до 6 и возвращает их сумму через `Dice.GetSum()`. `Player.Move(steps)` обновляет позицию по кругу из 40 клеток, начисляет 200 при прохождении «Старта» и возвращает признак прохождения круга.

### `Square.OnLand(Player player, Game game)`

Поведение определяется классом клетки.

- `Property.OnLand()` вызывает `Game.OfferPurchase(player, property)` для свободной собственности. Для чужой собственности применяет `CalculateRent(game)` нужного подкласса и вызывает `Game.ChargePayment(player, owner, rent)`. Для своей собственности выводится сообщение.
- `Tax.OnLand()` вызывает `Game.ChargePayment(player, null, Amount)` для обязательного платежа без получателя.
- `Chance.OnLand()` и `CommunityChest.OnLand()` вызывают `Deck.DrawCard()`, выводят описание, возвращают карту через `Deck.ReturnToBottom(card)` и затем выполняют `Card.ApplyEffect(player, game)`.
- `GoToJail.OnLand()` вызывает `Player.SendToJail()`. Игрок перемещается на позицию 10, получает признак `InJail`, а `JailTurns` сбрасывается.
- `Go.OnLand()`, `Jail.OnLand()` и `FreeParking.OnLand()` выводят сообщения о попадании на клетку.

### `Card.ApplyEffect(Player player, Game game)`

Штраф проходит через `Game.ChargePayment(player, null, Amount)`, бонус — через `Player.Receive(Amount)`, отправка в тюрьму — через `Player.SendToJail()`. При перемещении `Player.MoveTo(TargetPosition)` начисляет 200, если целевая позиция меньше исходной. Затем карта получает новую клетку через `Board.GetSquare(TargetPosition)` и сразу вызывает её `OnLand()`.

### `Game.CheckGameOver()` и `Game.AdvanceToNextPlayer()`

`CheckGameOver()` устанавливает статус `Finished`, если осталось не больше одного активного игрока. `AdvanceToNextPlayer()` меняет индекс только при статусе `InProgress` и пропускает банкротов.
